# AI Hiring Intelligence System

**AI-powered resume analysis with Google Gemini, Supabase authentication, persistent candidate history, and Excel reporting.**

[**Live Application**](https://ai-hiring-intelligence-system.streamlit.app/) | [**GitHub Repository**](https://github.com/valentinia-dotcom/AI-Hiring-Intelligence-System)

## Project Overview

The system helps recruiters analyze resumes, review candidate qualifications, and make evidence-informed hiring decisions while retaining human oversight.

## Key Features

- AI-assisted resume analysis
- Resume and job description comparison
- Explainable candidate insights
- Duplicate resume detection
- Supabase authentication and analysis history
- Excel/CSV reporting
- Human-reviewed recruitment decisions

## Technology Stack

- Python
- Streamlit
- Google Gemini API
- Supabase
- n8n (earlier workflow prototype)

## Project Evolution

**Phase 1 — n8n Automation Prototype**

Developed an automated workflow for resume processing and job description matching.

**Phase 2 — Python and Streamlit Application**

Extended the project into an interactive recruitment application with persistent analysis history, duplicate detection, and human review.

## Responsible AI

The application supports recruitment decisions rather than automatically selecting or rejecting candidates. Final hiring decisions remain with human reviewers.
